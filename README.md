## 🏁 Welcome to the Paddock

This project is a modern, responsive web application built from the ground up for Formula 1 fans. Designed to feel as fast and dynamic as the sport itself, it features an ultra-sleek UI with smooth animations, immersive photo galleries, and up-to-date driver and team grids.

## ✨ Features

- **🏎️ Dynamic Driver & Team Grids**: Browse beautifully designed cards featuring driver stats, national flags, and team branding. Hover over cards for butter-smooth zoom and depth effects.
- **🖼️ Cinematic Slideshow**: An immersive, auto-playing image slider highlighting iconic F1 moments with seamless crossfade transitions and tactile control buttons.
- **📱 True Responsive Design**: Optimized to look identical to the desktop layout on mobile devices by seamlessly scaling the viewport—no awkward reflows.
- **✨ Glassmorphism Navigation**: A sleek, dark, blur-backed navigation bar that ensures crystal-clear readability anywhere on the site, accented with interactive F1-red hover states.
- **🏁 Authentic Typography**: Uses **Titillium Web**, giving the entire application the aggressive, technical feel of official F1 broadcast graphics.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) powered by [Vite](https://vitejs.dev/) for lightning-fast HMR and optimized builds.
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) for utility-first styling and robust custom themes.
- **Animations**: [Framer Motion](https://www.framer.com/motion/) for fluid, physics-based UI transitions.
- **Icons**: [Lucide React](https://lucide.dev/) for crisp, lightweight iconography.

## 🚦 Getting Started

### 1. Clone the repository
\`\`\`bash
git clone https://github.com/yourusername/formula1-react.git
cd formula1-react
\`\`\`

### 2. Install dependencies
\`\`\`bash
npm install
\`\`\`

### 3. Start the engine (Development Server)
\`\`\`bash
npm run dev
\`\`\`
The app will be available at \`http://localhost:5173\`.

### 4. Build for Production
\`\`\`bash
npm run build
\`\`\`
This will generate highly optimized static files in the \`dist\` directory.
